## 1. Обзор проекта

**«Сетка Чудиков»** — это многопользовательская физическая 2D-песочница с моделированием сочленённых биомеханических существ (чудиков), обитающих на тороидальной координатной сетке.

Игроки могут:
- Конструировать уникальных чудиков в интерактивном векторном редакторе (задавая расположение головы, шарниров скелета, рёбер жесткости и активных мышечных волокон).
- Запускать существ в общий мир, соревноваться за ресурсы (еду), набирать массу, расти, эволюционировать и взаимодействовать по законам классической механики Ньютона.
- Управлять чудиком в реальном времени (руление, повороты, рывок с форсажем) или наблюдать за поведением автономных ботов.
- Использовать панель администратора для детальной настройки параметров гравитации, трения, спавна еды и физических констант мира.

## 2. Ключевые возможности и особенности

- ⚡ **100 FPS Серверная Физика на Go**: Высокоточный расчет сочлененных тел, упругих соударений, сопротивления вязкой среды и непрерывного обнаружения столкновений (CCD).
- 🎨 **Интерактивный Конструктор Существ**: Редактор с валидацией графа связности (BFS), авто-расчетом массы, момента инерции $I_{zz}$, центра масс ($CoM$) и векторов тяги мышц.
- 🚀 **Динамический Рывок (Dash / Boost)**: Увеличение скорости в $1.6\times$ с расходом накопленной еды ($2.0\text{ ед/сек}$) и защитой от вызова при нулевом балансе.
- 🍎 **Экосистема и Метаболизм**: Спавн питательных элементов, динамическое поглощение еды, разделение на хищников/собирателей и эволюционные мутации.
- 🌐 **Real-time Мультиплеер**: Синхронизация мира по протоколу WebSocket с интерполяцией на клиенте и поддержкой оффлайн-режима при разрыве связи.
- 📐 **Динамический интерфейс (Smart HUD)**: Автоматический расчет ограничивающего объема (Bounding Box) чудика с гарантией отсутствия перекрытия тела надписями.

## 4. Биомеханика и Конструктор Чудиков

Чудик строится на координатной сетке редактора. Каждое существо состоит из дискретных анатомических элементов:

| Элемент | Масса ($m$) | Назначение и биомеханическая функция |
| :--- | :---: | :--- |
| **Голова (`head`)** | **2.0** | Сенсорный центр, направление взгляда, челюсти для захвата еды |
| **Шарнир / Сустав (`joint`)** | **1.0** | Опорная ось вращения, делящая тело на рычаги движения |
| **Левое ребро (`edge-left`)** | **0.5** | Каркасный элемент жесткости, левый стабилизирующий плавник |
| **Правое ребро (`edge-right`)** | **0.5** | Каркасный элемент жесткости, правый стабилизирующий плавник |
| **Прямая мышца (`muscle-straight`)** | **0.8** | Линейный силовой привод (гармоническое сжатие/растяжение) |
| **Диагональная мышца (`muscle-diagonal`)** | **0.8** | Диагональный силовой привод (изгибание и поворот сегментов) |

### Алгоритм валидации конструкции
В редакторе работает алгоритм поиска в ширину (BFS):
1. Проверяется достижимость всех установленных узлов от головы чудика.
2. Несвязанные «висящие в воздухе» элементы подсвечиваются ошибкой.
3. Сохранение и выпуск в мир блокируются до исправления топологии графа.

## 5. Физический движок и Математическая модель

### 5.1. Центр масс и Момент инерции (Теорема Гюйгенса — Штейнера)
- **Общая масса:**
  $$M = \sum_{i=1}^{N} m_i$$
- **Центр масс ($CoM$):**
  $$X_{CoM} = \frac{1}{M}\sum m_i x_i, \quad Y_{CoM} = \frac{1}{M}\sum m_i y_i$$
- **Момент инерции относительно оси вращения ($I_{zz}$):**
  $$I_{zz} = \sum_{i=1}^{N} m_i \left( (x_i - X_{CoM})^2 + (y_i - Y_{CoM})^2 \right)$$

### 5.2. Модель мышц Кельвина — Фойгта
Сила сокращения мышечного волокна с фазой $\phi_j$:
$$L_j(t) = L_{0,j} \cdot \big(1.0 - 0.35 \cdot \sin^2(\omega t + \phi_j)\big)$$
$$\vec{F}_j = -k \big(L_j(t) - L_{0,j}\big) \hat{u}_j - c \big(\vec{v}_{rel} \cdot \hat{u}_j\big) \hat{u}_j$$

### 5.3. Гидродинамическое сопротивление среды
$$\vec{F}_{drag} = -\gamma_{Stokes} \vec{v} - \frac{1}{2} C_d \rho A_{eff} |\vec{v}| \vec{v}, \quad \tau_{drag} = -\beta_{rot} \cdot I_{zz} \cdot \omega$$

### 5.4. Численное интегрирование (Semi-implicit Euler, 100 FPS)
$$\omega(t + \Delta t) = \omega(t) + \frac{\tau_{net} + \tau_{drag}}{I_{zz}} \Delta t, \quad \theta(t + \Delta t) = \theta(t) + \omega(t + \Delta t) \Delta t$$
$$\vec{v}(t + \Delta t) = \vec{v}(t) + \frac{\vec{F}_{total}}{M} \Delta t, \quad \vec{r}(t + \Delta t) = \vec{r}(t) + \vec{v}(t + \Delta t) \Delta t$$

## 6. Игровые механики, Метаболизм и Ускорение (Dash)

### 6.1. Ускорение (Рывок / Dash)
- **Условие работы:** Рывок активен только при наличии запаса еды ($E_{food} > 0$).
- **Расход ресурса:** $2.0$ единицы еды в секунду.
- **Модификаторы:** Скорость $\times 1.6$, маневренность $\times 1.3$, активация шлейфа частиц и пламени ускорения.
- **Автоотключение:** При падении еды до $0$ ускорение мгновенно отключается, множитель сбрасывается до $1.0\times$, а игроку выдается подсказка.

### 6.2. Тороидальный мир
Координатная сетка замкнута по обеим осям. При выходе за границу $X > W$ существо непрерывно появляется с противоположной стороны $X = -W$.

## 7. Сетевой стек и Протокол WebSocket

Связь между браузером и сервером осуществляется через двунаправленный WebSocket-канал:

| Пакет | Направление | Описание |
| :--- | :---: | :--- |
| `init` | C $\to$ S | Регистрация игрока, передача имени и начальной конфигурации |
| `state_sync` | S $\to$ C | Высокочастотный снимок мира (координаты, углы, еда, лидерборд) |
| `input` | C $\to$ S | Управляющие команды (целевой угол, координаты курсора, флаг рывка `dash`) |
| `spawn_creature` | C $\to$ S | Выпуск нового существа из конструктора на карту |
| `admin_control` | C $\to$ S | Прямое административное управление любым выбранным чудиком |
| `chat_message` | C $\leftrightarrow$ S | Сообщения общего многопользовательского чата |

## 8. База данных, Аутентификация и Администрирование

- **База данных:** SQLite (`better-sqlite3`), сохраняется в локальный файл `creatures.db`.
- **Безопасность:** Пароли пользователей хешируются с солью через алгоритм `bcryptjs`.
- **Предустановленный аккаунт администратора:**
  - **Логин:** `joni`
  - **Пароль:** `PinokiO`
- **Панель Администратора:**
  - Изменение физических параметров мира (гравитация, вязкость, множитель рывка, расход еды).
  - Управление сущностями (ручной спавн ботов, очистка еды, респавн мира).
  - Просмотр системных логов сервера в реальном времени.

## 9. Пользовательский интерфейс и Управление

### Горячие клавиши и управление:
- **Пробел (Space)**: Активация рывка (Dash $\times 1.6$) при наличии еды.
- **A / D** (или $\leftarrow$ / $\rightarrow$): Поворот на 10° влево / вправо.
- **W / S** (или $\uparrow$ / $\downarrow$): Ручное ускорение / притормаживание.
- **ЛКМ (Клик по полю)**: Спавн порции еды в точку клика / Выбор чудика для слежения.
- **Колесо мыши (Scroll)**: Плавное масштабирование камеры (Zoom).
- **Перетаскивание с зажатой ЛКМ/ПКМ**: Свободное панорамирование камеры.

## 10. Инструкция по установке, сборке и запуску

### Системные требования:
- **Node.js**: Версия 18+ (рекомендуется Node 20 или 22)
- **Go**: Версия 1.20+ (для компиляции физического ядра `server-go`)
- **NPM**: Идет в комплекте с Node.js

### 1. Установка зависимостей проекта:
```bash
npm install
```

### 2. Сборка Go-сервера:
```bash
bash ./scripts/ensure-go.sh
```
*(Скрипт компилирует `server-go` в исполняемый бинарный файл `dist/go-server`)*

### 3. Запуск в режиме разработки:
```bash
npm run dev
```
Сервер запустится на едином порту `http://localhost:3000`.

### 4. Сборка и запуск Production:
```bash
npm run build
npm start
```
